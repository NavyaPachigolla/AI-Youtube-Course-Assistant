# AI YouTube Course Assistant using RAG

An AI-powered chatbot that answers questions from:

- YouTube course videos
- PDF notes/documents

Built using:
- Streamlit
- LangChain
- Sentence Transformers
- FAISS
- Groq LLM
- RAG Architecture

## Features

- YouTube transcript extraction
- PDF upload and processing
- Semantic search using FAISS
- AI-generated answers
- Conversational chatbot UI
- Retrieval-Augmented Generation (RAG)

## Tech Stack

- Python
- Streamlit
- LangChain
- Sentence Transformers
- FAISS
- Groq API
- Llama3-8b-8192
